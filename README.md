# MathWorks CAV

MATLAB/Simulink and RoadRunner work for WMU EcoCAR connected and automated vehicle (CAV) development.

Built with MATLAB/Simulink/RoadRunner R2026b.

## Contents

- `EIC_FW_Y1/` — MathWorks CAV tools training exercises: RoadRunner scene/scenario (`EIC.rrscene`, `EIC.rrscenario`), Simulink sensor and Unreal co-simulation models, and `RR_setup.m`. `Soln/` holds the reference solutions.

Generated build artifacts (`slprj/`, `*.slxc`) and the training slide deck are not tracked; see `.gitignore`.
